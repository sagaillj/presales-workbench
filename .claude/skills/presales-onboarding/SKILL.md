# Presales Onboarding

Read ../../../docs/ONBOARDING.md. Use a few conversational questions or resume the local /setup form. Meet the current user and capture goals/demo preferences; show the default workflows and let them opt out. Open the sample and their empty personal Workbench before requesting read-only source access. Only after approved source choices, verify their own identity, manager, segment, geography, timezone and CRM mappings; preserve source/confidence and unknowns. Run ../../../docs/FIRST-TEST.md and save a private readout. Demo data is never identity evidence. No inherited permissions, automatic writes, global settings changes or recurring jobs.
