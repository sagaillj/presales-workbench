# Presales Weekly Qci

Read ../../../docs/QCI.md and the current private profile/goals. Use the newly verified manager and the real reviewed source extent. Preserve timestamps, stable evidence chains, manual notes, contradictory evidence and gaps. Earlier behavior is baseline; one positive example is not sustained improvement. Save the personal evidence packet and update Coaching using ../../../docs/DATA-CONTRACT.md. Drafts, adoption, customer acceptance and revenue are separate states. Do not send the manager update or invent goals, metrics or ratings.

Check workspace/profile.json preferences.modules before running this workflow. Respect opt-outs and source-read approvals from onboarding; a selected workflow is not source access or write permission.

When presenting an action, follow ../../../docs/ACTION-CARDS.md: question/request first, short recommended answer, optional context and unsent replies. Preserve settled decisions and user progress.
