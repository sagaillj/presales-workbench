# Workbench v0.6.0

A simpler first pilot run, with more control over ongoing usage.

- Set up in Codex: a short get-acquainted flow, the first approved source review, then normal Workbench with genuine tasks and two clearly labeled orientation cards. No browser setup questionnaire.
- Daytime communications checks at 9 AM, noon and 3 PM are off for new users. Daily 5:30 PM upkeep remains available after consent; daytime checks can be enabled later in Settings.
- Save tasks for later in Archive, restore them, or remove them from the archive. Existing notes, sources and completion history are preserved.
- Open verified Slack conversations directly in the desktop app, with the original browser link retained.
- Review time-savings estimates and editable assumptions in the updated Metrics and Settings views. Estimates stay distinct from measured time and billed cost.
- Prepare replies from the latest conversation and verified completed actions. Missing demo prep can become a sourced booking task; automatic internal booking starts off and requires the user's own approval.

The starter contains fictional examples and generic workflows, not another user's accounts, customer records, credentials, permissions or active schedules. External writes and sends remain off until specifically authorized. Existing installations keep their own private workspace during supported upgrades.
