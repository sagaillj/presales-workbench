# Weekly coaching and QCI

Run only when the relevant workflow is enabled in workspace/profile.json and its required sources are approved. Report skipped or inaccessible sources without silently expanding scope.
Read the current user’s researched profile, current quarterly goals, previous weekly packet and source coverage. Do not use the demo practices or another person’s manager feedback as the user’s plan. If goals are missing, ask a focused question and still prepare a clearly labeled evidence preview.

Build a deduplicated inventory of work calls actually attended in the selected week. Include relevant internal work, but do not infer attendance from an invite. Review accessible transcripts/recordings against applicable goals, using the actual speaker, timestamp and reviewed extent. A summary is triage evidence, not proof of a behavior throughout a call. Unreviewed segments are unknown, not misses.

Capture manager coaching, customer/rep feedback, recognition, missed commitments, useful artifacts and deal/customer outcomes from available authorized sources. Distinguish direct observation, customer report, manager observation and recommendation. Preserve contrary evidence and exact source coverage.

Use the chain: feedback → behavior to try → a later eligible call → observed behavior → customer/deal result → next action. Behavior before the feedback is baseline evidence, not proof the feedback was applied. One strong example does not demonstrate consistent improvement or an official rating.

Keep at most a few useful active practices, each with a prompt and proof rule. For example, asking for desired outcomes, showing the relevant finished result first, or closing on the decision/owner/date can be practices when they fit the user’s actual goals. Do not insert irrelevant features to satisfy a generic template.

Save a concise weekly packet under `workspace/personal/qci/`: highlights, gaps, customer/deal impact, goal progress, next-week focus, source-linked moments, artifacts, review-ready snippets and source gaps. Maintain an index. Preserve manual additions and stable evidence/feedback IDs; reuse unchanged source fingerprints and reassess changed or pending material only.

Before preparing or refreshing an unsent manager update, follow ACTION-CARDS.md: read the latest exact incoming and sent manager conversation, preserve answered questions and completed outcomes, and respond naturally to any actual remaining ask. Verify the manager’s current name and identity and save the exact Slack workspace/conversation binding with the original browser fallback when available. Reuse an existing ready draft to that person rather than creating multiple competing messages. Never send it automatically. Publish the saved review and practices to Coaching using DATA-CONTRACT.md; it should be readable without another model run.

For a quarterly draft, use the actual review questions and current goals, group the weekly evidence and mark unsupported claims as needing evidence. Do not invent adoption, hours saved, revenue lift, technical acceptance or competency ratings. Efficiency and business impact remain distinct; use measured or explicitly user-reported figures and name missing baselines.
